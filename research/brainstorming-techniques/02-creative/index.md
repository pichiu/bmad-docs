# Creative Brainstorming Techniques

> 創意類腦力激盪技術 - 突破框架、激發創新

## 類別概述

創意類技術是最大的技術類別，包含 11 種技術，專注於打破既有思維模式、挑戰假設、建立意想不到的連結。這些技術特別適合需要突破性創新的情境。

```mermaid
mindmap
  root((Creative))
    假設挑戰
      What If Scenarios
      First Principles
      Reversal Inversion
    連結建構
      Analogical Thinking

    跨界創新

      Concept Blending
    時空探索
      Time Shifting
    反向思維
      Reverse Brainstorming
    多感官
      Sensory Exploration
```

## 核心特性

| 特性 | 說明 |
|------|------|
| 假設挑戰 | 質疑既有信念和限制 |
| 連結建構 | 在看似無關的概念間建立橋樑 |
| 跨界遷移 | 從其他領域借用成功模式 |
| 發散思維 | 最大化想法多樣性 |

## 技術選擇流程

```mermaid
flowchart TD
    A[需要創意突破?] -->|是| B{目前狀態?}

    B -->|被假設困住| C[First Principles]
    B -->|想法太相似| D[Cross-Pollination]
    B -->|需要新視角| E{偏好方式?}

    E -->|類比思考| F[Analogical Thinking]
    E -->|隱喻轉化| G[Metaphor Mapping]
    E -->|強制連結| H[Forced Relationships]

    B -->|卡住了| I{嘗試什麼?}
    I -->|反向思考| J[Reverse Brainstorming]
    I -->|假設情境| K[What If Scenarios]
    I -->|時間維度| L[Time Shifting]

    B -->|需要融合創新| M[Concept Blending]
```

## 能量等級

| 能量 | 技術 |
|------|------|
| 高 | What If Scenarios, Concept Blending |
| 中-高 | Cross-Pollination, Forced Relationships |
| 中 | Analogical Thinking, First Principles, Metaphor Mapping |
| 中-低 | Reversal Inversion, Time Shifting, Sensory Exploration |
| 低 | Reverse Brainstorming |
