# Collaborative Brainstorming Techniques

> 協作類腦力激盪技術 - 強調團隊動力與多元聲音

## 類別概述

協作類技術專注於團隊互動，透過結構化的協作流程，確保每位成員都能貢獻想法，建立共識與活力。

```mermaid
mindmap
  root((Collaborative))
    Yes And Building
      肯定式累加
      即興喜劇起源
      建立安全環境
    Brain Writing
      沉默書寫
      內向者友善
      避免群體迷思
    Random Stimulation
      隨機刺激
      打破心理障礙
      強制連結
    Role Playing
      角色扮演
      多元觀點
      利害關係人同理
    Ideation Relay
      限時接力
      高能量突破
      防止過度思考
```

## 核心特性

| 特性 | 說明 |
|------|------|
| 團隊動力 | 透過結構化流程激發集體智慧 |
| 多元聲音 | 確保內向者與外向者都能貢獻 |
| 共識建立 | 在創意過程中逐步建立團隊共識 |
| 心理安全 | 創造無批判的安全表達環境 |

## 使用時機

```mermaid
flowchart TD
    A[需要團隊協作?] -->|是| B{團隊特性?}
    B -->|內向者多| C[Brain Writing]
    B -->|外向者多| D[Yes And Building]
    B -->|混合型| E{時間壓力?}
    E -->|有| F[Ideation Relay]
    E -->|無| G{需要多元視角?}
    G -->|是| H[Role Playing]
    G -->|卡住了| I[Random Stimulation]
```

## 能量等級

- **高能量**: Yes And Building, Ideation Relay Race
- **中等能量**: Role Playing, Random Stimulation
- **低能量**: Brain Writing Round Robin
